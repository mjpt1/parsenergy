# Differences from requirements.txt (which targets Docker/ASGI with Postgres):
#   - dropped: gunicorn, uvicorn, channels-redis, celery, redis, psycopg2-binary

#      default — for MySQL add a driver, see the note at the bottom).
#   - 'channels' is kept because it is in INSTALLED_APPS, but the live WebSocket
#     telemetry is inactive under WSGI (the dashboards use AJAX polling instead).
#   - compiled packages are left unpinned so pip picks wheels matching the Python
#     version your cPanel app uses (tested with Python 3.11–3.13).
